# Consultas à orientação

Uma consulta por impasse que o grupo **não pode ou não deve** resolver
sozinho: mudança de modelagem, mudança de base, mudança no objetivo
declarado.

## A regra desta pasta

Nunca chegar só com a pergunta. Cada consulta traz, nesta ordem:

1. **O problema**, com os números medidos — não com a impressão de quem
   implementou.
2. **A prova de que não é erro nosso** — o controle que mostra que o
   método funciona onde deveria funcionar.
3. **O que já tentamos**, e por que cada tentativa não resolveu.
4. **As saídas possíveis**, cada uma com custo, o que entrega e o risco.
5. **A inclinação do grupo**, declarada.
6. **As perguntas**, numeradas, respondíveis em uma frase cada.

O objetivo é que a orientação gaste o tempo dela decidindo, não
reconstruindo o diagnóstico.
